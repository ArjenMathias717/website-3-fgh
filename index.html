Rebecca Own Fast-Growing Hierarchy

The Rebecca Own Fast-Growing Hierarchy is a custom fast-growing hierarchy developed as an exploration of rapidly growing functions, ordinal notation, and recursive mathematical systems.

How it Started

The Rebecca Own Fast-Growing Hierarchy was developed as part of an exploration of large numbers, fast-growing functions, ordinal notation, and increasingly powerful mathematical hierarchies.

Notation

The hierarchy uses its own notation. The symbol n represents the numerical input of a function, while the subscript indicates the level or ordinal structure associated with the function. Custom symbols and operators introduced by the system are defined explicitly in the sections below.

Rebecca Ordinal

The Rebecca Ordinal is the ordinal structure used by the Rebecca Own Fast-Growing Hierarchy. Its exact rules and notation are defined as part of the system rather than being assumed to be standard notation.

Base Function

The base function of the hierarchy is written f_o(n) = (2²)↑↑n. Here, (2²) represents the Olaf Ordinal structure used by the system, while n determines the height of the tetration operation.

Examples

Using the numerical simplification (2²) = 4 for ordinary evaluation, f_o(1) = 4 and f_o(2) = 4↑↑2 = 4⁴ = 256. The structural notation is retained when the Olaf Ordinal itself is being discussed.
